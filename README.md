# Help me learn

[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE) [![PRs welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md) [![Português](https://img.shields.io/badge/lang-pt--BR-blue.svg)](README.pt-BR.md)

**Learn programming together, one small challenge at a time.** Try the [first challenge](challenges/01-checklist/), [send a solution](CONTRIBUTING.md), or [suggest something to learn](#share-something-i-can-try). **[Leia em português](README.pt-BR.md).**

I'm Toledo. I've worked on projects like WinDot, Dot Com, AndroBits, and Infall (Currently private as they are in progress). I'm making "Help me learn" my only public repository so I can learn programming with others. I want to try things hands-on, talk with other programmers about how they approach problems, and share what I learn along the way.

If you found this because you're learning too, you're welcome to try the same exercises, share what you discover, and ask questions of your own.

## Share something I can try

Have a tip, a concept you think every beginner should know, a small exercise, or an unfinished project I could explore? Share it in Discussions. If you can, tell me:

- What could I learn from it?
- What should I know before I start?
- What's one thing I could try first, and how could I tell if it worked?

If you're sharing a project, please link to the original, tell me what I can reuse, and point me to one small change I can try. You can post in English or Portuguese. Please leave out passwords, API keys, and private information.

## Learn alongside me

I'll share what I tried, where I got stuck, and what I learned. If I get stuck, a hint or a question that helps me find the next step is welcome. If you try the same exercise, I'd love to see how you approached it.

Use a pull request to suggest changes to this repository. I'll review the proposed changes and decide what goes into the main branch. The steps are in [CONTRIBUTING](CONTRIBUTING.md), and everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).
