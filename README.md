# Help me learn

[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE) [![PRs welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md) [![Português](https://img.shields.io/badge/lang-pt--BR-blue.svg)](README.pt-BR.md)

**Small programming exercises, any language, friendly feedback.** Pick a challenge, solve it your way, and send your solution as a pull request. No experience needed, and you can do it from the GitHub website without installing git. **[Leia em português](README.pt-BR.md).**

## Challenges

| # | Challenge | Teaches |
|---|-----------|---------|
| 01 | [Messy list to Markdown checklist](challenges/01-checklist/) | strings, loops, edge cases |

Each challenge takes about 30 minutes and has a `solutions/` folder. Add one file, open a pull request, and tell us one thing you figured out and one thing you'd like feedback on. A reference Python solution with tests shows the format. More challenges are coming: have an idea? Open a "Challenge idea" issue.

## How to learn here

1. Try the challenge on your own before reading the reference solution.
2. If you get stuck, ask for a hint in [Discussions](https://github.com/redsocialwood-png/Help-me-learn/discussions). A question that points to the next step helps more than a finished answer.
3. After it works, compare approaches with others.
4. Share what you learned and what you would improve.

Steps to contribute are in [CONTRIBUTING](CONTRIBUTING.md). Everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## Share something I can try

Have a tip, a concept every beginner should know, a small exercise, or an unfinished project I could explore? Share it in Discussions. If you can, tell me what I could learn from it, what I should know first, and one thing to try and how to tell if it worked. If it's a project, link to the original and point me to one small change. English or Portuguese. Leave out passwords, API keys, and private information.
