# Help me learn (Português)

[English](README.md) · [Contribuir](CONTRIBUTING.md) · [Código de Conduta](CODE_OF_CONDUCT.md)

**Aprendendo programação juntos, um desafio pequeno de cada vez.** Tente o [primeiro desafio](challenges/01-checklist/), [mande uma solução](CONTRIBUTING.md) ou [sugira algo para eu aprender](#compartilhe-algo-para-eu-tentar).

Eu sou o Toledo, e estou aprendendo a programar. Trabalhei em projetos como WinDot, Dot Com, AndroBits e Infall (privados por enquanto, porque ainda estão em andamento). Este é meu único repositório público: quero aprender com outras pessoas, testar na prática, conversar sobre como cada um resolve os problemas e dividir o que aprendo.

Se você também está aprendendo, é bem-vindo: faça os mesmos exercícios, conte o que descobriu e pergunte o que quiser. Pode escrever em português ou inglês.

## Compartilhe algo para eu tentar

Tem uma dica, um conceito que todo iniciante deveria conhecer, um exercício pequeno ou um projeto inacabado que eu possa explorar? Conte nas [Discussions](https://github.com/redsocialwood-png/Help-me-learn/discussions). Se puder, diga:

- O que eu posso aprender com isso?
- O que preciso saber antes de começar?
- Qual é uma coisa que posso tentar primeiro, e como saber se deu certo?

Se for um projeto, coloque o link do original, diga o que posso reaproveitar e uma pequena mudança que eu possa tentar. Não coloque senhas, chaves de API nem informações privadas.

## Aprenda comigo

Vou contar o que tentei, onde travei e o que aprendi. Se eu travar, uma dica ou uma pergunta que me leve ao próximo passo ajuda mais do que a resposta pronta. Se você fez o mesmo exercício, adoraria ver como pensou.

Para sugerir mudanças, use um pull request. Os passos estão em [CONTRIBUTING](CONTRIBUTING.md). Eu reviso e decido o que entra no `main`.

## Como aprender aqui

1. Tente resolver o desafio sozinho antes de consultar a solução de referência.
2. Procure uma dica ou faça uma pergunta se travar.
3. Compare abordagens depois de chegar a uma solução funcional.
4. Conte o que aprendeu e o que gostaria de melhorar.
