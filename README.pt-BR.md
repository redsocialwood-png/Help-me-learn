# Help me learn (Português)

[English](README.md) · [Contribuir](CONTRIBUTING.md) · [Código de Conduta](CODE_OF_CONDUCT.md)

**Exercícios pequenos de programação, em qualquer linguagem, com feedback amigável.** Escolha um desafio, resolva do seu jeito e mande a solução em um pull request. Não precisa de experiência, e dá para fazer pelo site do GitHub, sem instalar o git.

## Desafios

| # | Desafio | Ensina |
|---|---------|--------|
| 01 | [Lista bagunçada em checklist Markdown](challenges/01-checklist/) | strings, laços, casos de borda |

Cada desafio leva cerca de 30 minutos e tem uma pasta `solutions/`. Adicione um arquivo, abra um pull request e conte uma coisa que descobriu e uma sobre a qual quer feedback. Tem uma solução de referência em Python com testes para mostrar o formato. Mais desafios virão: tem uma ideia? Abra uma issue "Challenge idea".

## Como aprender aqui

1. Tente o desafio sozinho antes de ler a solução de referência.
2. Se travar, peça uma dica nas [Discussions](https://github.com/redsocialwood-png/Help-me-learn/discussions). Uma pergunta que aponta o próximo passo ajuda mais que a resposta pronta.
3. Depois que funcionar, compare abordagens com os outros.
4. Conte o que aprendeu e o que melhoraria.

Os passos para contribuir estão em [CONTRIBUTING](CONTRIBUTING.md). Todos seguem o [Código de Conduta](CODE_OF_CONDUCT.md).

## Compartilhe algo para eu tentar

Tem uma dica, um conceito que todo iniciante deveria conhecer, um exercício pequeno ou um projeto inacabado que eu possa explorar? Conte nas Discussions. Se puder, diga o que eu posso aprender, o que preciso saber antes, e uma coisa para tentar primeiro e como saber se deu certo. Se for um projeto, coloque o link do original e uma pequena mudança que eu possa fazer. Português ou inglês. Não coloque senhas, chaves de API nem informações privadas.
